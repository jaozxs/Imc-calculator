⚖️ Calculadora de IMC

Aplicação web que calcula o Índice de Massa Corporal (IMC), exibindo a classificação, tabela comparativa e feedback visual de acordo com o resultado.

🚀 Funcionalidades

Cálculo automático do IMC

Classificação por faixa (magreza, normal, sobrepeso, obesidade)

Tabela dinâmica com faixas de IMC

Validação de entradas

Feedback visual por cores

Layout responsivo

🛠️ Tecnologias

HTML5

CSS3

JavaScript (ES6+)

▶️ Como usar

Informe altura e peso e clique em Calcular.
